## Завдання 1. Перевірка доступності вебсайтів

### Мета

Створити Bash-скрипт, який перевіряє доступність вебсайтів за допомогою `curl` і зберігає результати у файл логів.

### Як працює скрипт

1. Зберігає URL вебсайтів у масиві.
2. Послідовно надсилає HTTP GET-запити за допомогою `curl`.
3. Використовує параметр `-L`, щоб переходити за HTTP-переадресаціями.
4. Перевіряє HTTP-статус відповіді: `200` означає `UP`, інші результати — `DOWN`.
5. Виводить результати в термінал і записує їх у `website_status.log`.

### Як запустити

Потрібні Bash і `curl`. У Linux або Ubuntu через WSL відкрийте термінал у корені проєкту та виконайте:

```bash
bash task-1-website-checker/check_websites.sh
```

Результати останнього запуску будуть збережені у файлі `task-1-website-checker/website_status.log`.

### Основні команди, які використовуються

* `curl` — надсилання HTTP-запитів.
* `for` — послідовний перебір URL.
* `if` — перевірка умови.
* `echo` — виведення та запис тексту.
* `>` — створення або очищення файлу.
* `>>` — додавання тексту в кінець файлу.
